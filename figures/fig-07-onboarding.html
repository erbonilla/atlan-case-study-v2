1 No defaults Language is a choice

English and Español are presented as equal options, in the same type weight, in the same button shape. Neither inherits "default" status from device locale.

2 Voice ratio 55 % Hero · 45 % Sage

The only surface where Hero leads. "Welcome" eyebrow in Coral, warm title, autonomy-supportive framing. Hands off to Sage by the second sentence.

3 Calibration, not scoring No right answers

Four questions, three options each, no "good athlete / bad athlete" framing. Each answer tunes a real product setting — autonomy, depth density, notification cadence.

4 Transparency Inferred settings, shown

Step 04 surfaces what the app inferred from the user's answers. No hidden personalization. The user can see, and adjust, what the calibration did.

01

Voice posture, not vocabulary, is what carries. "Built for athletes with lives" doesn't translate literally as "Hecho para atletas con vidas." It translates as "Hecho para quienes entrenan entre todo lo demás" — the same Quiet Sage posture in Spanish-native phrasing.

02

The Sage 70 / Hero 30 ratio holds in Spanish. Voice ratio is set by tone, not by literal word count. Spanish review is a separate audit pass with a native ES copy editor; not a translation memory output.

03

Hierarchy and layout remain identical. No "Spanish takes more characters, so the button got smaller." Type tokens, button heights, and spacing are language-invariant. Long ES strings flow to two lines; they do not shrink.

04

Calibration questions are written in Spanish first for Spanish users, not translated. The Grit Assessment in ES is authored by a Spanish-native copywriter using the same SDT framing. Same answers, same calibration, different mother tongue.

Most products treat Spanish as a translation layer. Atlan treats it as a first language. Same product, built twice, with the same posture.
