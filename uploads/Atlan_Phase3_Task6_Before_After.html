Element accounting

Every removed element, accounted for. Every relocation, sourced to a cluster.

Element Verdict Atlan location Reasoning
147-day streak counter Removed — The Optimizer arrives with full drive; gamification mechanics imported from consumer fitness are read as patronizing. Streak as identity makes the missed day catastrophic. · Output 2 · Cluster 1
2CTL / ATL / TSB 90-day chart Relocated Behind "Why · Weekly load" modal in the Atlan weekly-arc chip The science is real and matters. The chart density is not the right surface for the 9 PM user. Depth on demand, not depth on display. · Output 2 · Cluster 4
3HR Zone pie + Power Curve + Sleep bars Relocated Post-session detail view; opt-in only Per-session metrics belong in the session detail surface, not the dashboard. The dashboard is the morning glance, not the analytics suite. · Output 2 · Cluster 4
4"This Week's Plan" with red MISSED row Reframed Weekly arc shows load adapted; missed sessions absorbed into the curve, not marked red Disruption is a planning input, not a failure event. The arc preserves training signal without rendering the missed Wednesday as a wound. · Output 2 · Cluster 3
5Notification badges (3 unread) Removed — Notification policy is minimal by default per Step 04 of onboarding. No bell badge persists on the dashboard surface; alerts arrive only at the configured moments. · Output 2 · Cluster 1
6"Compare with peers" + percentile rank Removed — SDT-aligned: competence-shaped feedback works for this cohort; comparison-shaped feedback actively repels them. Ranking against a peer group does not change behavior for The Optimizer; it just shows them a leaderboard they didn't want. · Output 2 · Cluster 5
5-card KPI strip (CTL · ATL · TSB · FTP · VO2) Consolidated Single "Load · On track" metric chip with "i" affordance Five interpretable numbers becomes one summary state. The underlying numbers remain — they live behind the "i" — but the dashboard reports the meaning, not the inputs. · Output 2 · Cluster 4
Multi-tab navigation (Dashboard / Plans / Training / Calendar / Analytics / Community) Consolidated Quiet header with brand + date; navigation lives in a single gesture-revealed surface Six tabs is six decisions on landing. The dashboard answers two questions: what's today, and how is the week going. Everything else is a navigation depth the user reaches when they need it. · Output 2 · Cluster 2
Coach feedback panel inline on dashboard Relocated Inbox / messages view, separate surface Coach interaction is asynchronous communication, not a glanceable metric. Placing it on the dashboard makes the app feel like an inbox — another thing the user is behind on. · Output 2 · Cluster 2
Goal progress bar ("73% of season target") Removed — The Optimizer is rarely racing. They train because the alternative is worse. A progress bar toward an external goal misreads the motivation structure — and the "73% complete" framing implies the rest of the year is a deficit. · Output 2 · Cluster 1

Subtraction is not minimalism for its own sake. Every removed element has a destination — relocated to depth-on-demand, consolidated into a state summary, or cut because it served a user Atlan isn't built for.

Sources Phase 2 Output 1 (upper-right quadrant claim: depth + autonomy); Output 2 Clusters 1, 2, 3, 4, 5 (every removal sourced to a documented cluster); Output 4 voice spec (Sage subtraction logic — the dashboard surface, like the active workout, leans Sage-dominant).
